# Additional exercises

Questions supplied with the lab material. These are optional extensions to the main experiment.

1. Network Communication Scenario
Scenario:
A testing engineer wants to verify whether the network connection between a client and server is working correctly. Instead of sending complex data, the engineer uses an Echo Server.
Question:
Why is an Echo Server useful for testing network communication?
2. Server Not Running Scenario
Scenario:
A student runs the echo client program, but the server program is not started.
Question:
What will happen when the client tries to connect to the server?
3. Port Conflict Scenario
Scenario:
Another application is already using port 65432 when the echo server starts.
Question:
What error may occur and how can it be resolved?
4. Client Sends Large Data Scenario
Scenario:
A client sends a message larger than 1024 bytes to the echo server.
Question:
What will happen in the current program?
5. Multiple Clients Scenario
Scenario:
Five students try to connect to the echo server simultaneously.
Question:
Will the current server program handle multiple clients at the same time?
